# Lightning AI Paraphrase Fine-Tuning

Alternative to Tinker API using Lightning AI platform.

## 🚀 Quick Start

1. Go to https://lightning.ai/onboarding-chat
2. Sign up / Log in
3. Create a new Studio
4. Upload the training script
5. Run training

## 💰 Pricing

- **Free tier:** 15 credits/month
- **Paid:** ~$0.50/hour for GPU
- **Training cost:** ~$2-5 for full fine-tuning

## 📁 Files

- `train_lightning.py` - Training script
- `requirements.txt` - Dependencies
