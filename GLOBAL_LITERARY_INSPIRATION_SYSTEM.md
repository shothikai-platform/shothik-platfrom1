#### 🇧🇩 Humayun Ahmed (Bangladesh)

- "Debi" (The Goddess) - Psychological thriller
- "Nondito Noroke" (In Blissful Hell) - Existential novel

## 📖 READING RECOMMENDATIONS ENGINE

### Based on What You're Writing:

```typescript
interface ReadingRecommendation {
  // If writing family saga
  if (genre === 'family_saga') {
    return [
      { book: "One Hundred Years of Solitude", why: "Multi-generational structure" },
      { book: "The God of Small Things", why: "Non-linear family narrative" },
      { book: "The Cairo Trilogy", why: "Social change through family" }
    ];
  }
  
  // If writing about identity
  if (theme === 'identity') {
    return [
      { book: "Midnight's Children", why: "Identity and nation" },
      { book: "The Namesake", why: "Diaspora identity" },
      { book: "Gora", why: "Cultural identity crisis" }
    ];
  }
  
  // If writing romance
  if (genre === 'romance') {
    return [
      { book: "Love in the Time of Cholera", why: "Epic love across decades" },
      { book: "Norwegian Wood", why: "Melancholic young love" },
      { book: "The Home and the World", why: "Love and politics" }
    ];
  }
}
```
